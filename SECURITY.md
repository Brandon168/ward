# Security

Ward handles vault keys and passwords. Please report problems privately through
[GitHub's private vulnerability reporting](https://github.com/Brandon168/ward/security/advisories/new), not in a public
issue. Problems in BW Lite itself should also be reported upstream through
[its private vulnerability reporting](https://github.com/yowmamasita/bw-lite/security/advisories/new).
Problems in Bitwarden or Vaultwarden belong with those projects.
